## About Me

我曾在 University of York 学习 Human-Centred Interactive Technologies（HCIT），现在关注 AI 产品、用户体验，以及复杂技术的通俗表达。

我不只关心模型能否实现，也关心技术能否进入真实使用场景——让用户看得懂、信得过、愿意用。

## What I'm Working On

- 🤖 探索 LLM、RAG 与 AI Agent 如何转化为清晰可用的产品体验
- 🧩 制作面向初学者的 AI 知识图解与内容系统
- ✍️ 记录 AI 产品分析、产品体验与项目复盘
